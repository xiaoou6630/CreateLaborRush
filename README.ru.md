# Create: Labor Rush

[![Modrinth](https://img.shields.io/badge/Modrinth-Create_Labor_Rush-00AF5C?logo=modrinth&logoColor=white)](https://modrinth.com/project/iD2FJnQa)

[简体中文](README.md) | [English](README.en.md) | **Русский**

Хлещите рабочих поводком, чтобы они работали быстрее, зачаровывайте поводки и колокола на «Огненный аспект» / «Громовержец», созывайте всех ударом в колокол — а если перегнуть палку, начнётся восстание рабочих. Ещё можно надеть на рабочих колпак позора, шляпу капиталиста и табличку с собственноручно написанным текстом. 19 достижений ждут разблокировки.

---

## Как пользоваться

| Действие | Эффект |
|----------|--------|
| **Поводок** — ЛКМ по рабочему | Эффект «Работать!» на 90 секунд |
| **Колокол** — ПКМ | Ускоряет всех рабочих в радиусе 16 блоков |
| **Shift + ЛКМ** | Громовая плеть (5 ударов, зона 5 блоков) |

| Зачарование поводка | Уровень | Размер партии |
|---------------------|---------|---------------|
| Обычный | Work I | По умолчанию |
| Огненный аспект I | Work II | 32 |
| Огненный аспект II | Work III | 64 |
| Громовержец | Work III | 64 |

## Что нового

- **Зачарованный колокол**: «Огненный аспект» или «Громовержец» на колоколе, эффекты сохраняются после перезапуска
- **Восстание рабочих** (по умолчанию выключено): заражение, главарь, бафф силы, выкуп изумрудами
- **Бунт горничных**: сами подбирают оружие, 22 реплики по Touhou
- **19 достижений**: от «Первого удара» до «Министра наказаний»
- **Эффект молнии**: синий столб → разряд → ударная волна → электрические дуги
- **Графический конфиг**: настройка прямо в игре через «Моды → Config», применяется сразу
- **Мультиплеер**: главный конфиг — серверный; менять может только админ, изменения рассылаются всем
- **Колпак позора / Шляпа капиталиста**: модели-шлемы (3 брони / 1 прочность), горничные тоже носят
- **Табличка** (пока отключена): обычная подвесная табличка вешается в слот нагрудника или на рабочего, текст пишется в 4 строки
- **Картина-лозунг**: 4×3, «Время — деньги, эффективность — жизнь»
- **Локализация**: китайский / английский / русский

## Как подавить восстание

| Способ | Действие | Примечание |
|--------|----------|------------|
| Сила | Убить всех восставших | Долгий откат забастовки в этой зоне |
| Подождать | Дождаться конца таймера | Восстание кончается само, откат короче |
| Выкуп | ПКМ **изумрудами** по главарю | Заплатить достаточно — конец миром |
| Колокол | Ударить в колокол **внутри зоны восстания** | Конец миром; достижение «Миротворец» |
| Громовержец | Поводок с «Громовержцем» + **Shift + ЛКМ** по восставшим | Достижение «Повелитель гроз» |

> `enableRebellion` управляет только **запуском новых** восстаний. Уже начавшееся идёт своим ходом, и все пять способов выше работают.

## Кепки и таблички

| Предмет | Крафт | Примечание |
|---------|-------|------------|
| **Колпак позора** | Create: картон ×5 | Слот шлема, 3 брони / 1 прочность, горничные тоже носят |
| **Шляпа капиталиста** | Чёрная шерсть ×4 + красный краситель ×1 | Те же характеристики, чёрный фетровый цилиндр |
| **Картина-лозунг** | как обычная картина | 4×3, «Время — деньги / Эффективность — жизнь» |

> В 1.20.1 для этой картины нужна стена минимум **4 блока в ширину и 3 в высоту**, иначе она не попадёт в случайный выбор.

Табличка — это **обычная подвесная табличка**, новых предметов нет. Текст хранится на ней самой, поэтому при установке блоком он сохраняется.

> **В этой версии табличка отключена** (есть нерешённые проблемы с отрисовкой текста). Таблица ниже описывает замысел; сейчас ПКМ по табличке не делает ничего особенного.

| Действие | Эффект |
|----------|--------|
| Табличка + **ПКМ по воздуху** | Открыть экран написания (4 строки) |
| Табличка + **присесть + ПКМ по воздуху** | Переложить в слот нагрудника (старый нагрудник — в руку) |
| Табличка + **ПКМ по рабочему** | Повесить табличку на рабочего (тратится одна) |
| **Присесть + пустая рука + ПКМ по рабочему** | Снять табличку обратно |

## Конфиг

Настраивается в игре: **Список модов → Create: Labor Rush → Config** (применяется сразу, перезапуск не нужен), либо вручную в `config/createlaborrush-common.toml`.

| Параметр | По умолчанию | Диапазон | Описание |
|----------|--------------|----------|----------|
| `destroyChance` | 0.15 | 0.0–1.0 | Шанс уничтожения предмета при работе |
| `destroyRatioMin` | 0.2 | 0.0–1.0 | Минимальная доля потерь |
| `destroyRatioMax` | 0.5 | 0.0–1.0 | Максимальная доля потерь |
| `enableRebellion` | false | bool | Включить восстания (только запуск новых) |
| `rebellionTriggerTime` | 300 | 10–3600 | Сколько секунд суммарной работы нужно до возможного восстания |
| `rebellionChance` | 0.05 | 0.0–1.0 | Базовый шанс на каждую проверку раз в 10 секунд |
| `rebellionDuration` | 300 | 5–600 | Длительность восстания (секунды) |
| `rebellionRadius` | 5 | 1–32 | Радиус обнаружения (блоки) |
| `canDestroyDevices` | true | bool | Ломают ли восставшие устройства |
| `destroyCooldown` | 10 | 1–60 | Откат между разрушениями у одного бунтаря (секунды) |
| `destroyIntensity` | 0.5 | 0.0–1.0 | Интенсивность разрушений |

В мультиплеере главный конфиг — **серверный**: изменения принимаются только от админа (OP либо хозяина одиночной/LAN-игры) и рассылаются всем остальным; чужие правки отклоняются с сообщением в чате. Значения с сервера никогда не записываются в локальный файл конфига клиента.
