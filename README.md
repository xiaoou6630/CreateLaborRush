# Create: Labor Rush v2.0

拴绳抽打加速工人，附魔解锁火焰批量/引雷特效，敲钟全员号召，压迫过头触发工人起义，19 个成就等你解锁。

---

## 用法

| 操作 | 效果 |
|------|------|
| **拴绳**左键工人 | 90 秒"干活！"效果 |
| **钟**右键 | 16 格内全体工人加速 |
| **Shift+左键** | 闪电五连鞭（5 格AOE） |

| 拴绳 | 等级 | 批量 |
|------|------|------|
| 普通 | Work I | 默认 |
| 火焰附加 I | Work II | 32 |
| 火焰附加 II | Work III | 64 |
| 引雷 | Work III | 64 |

## v2.0 新特性

- **附魔钟**：钟可附魔火焰附加/引雷，敲响触发特效，持久化存储
- **工人起义**（默认关闭）：传染、首领、力量Buff、绿宝石谈判
- **女仆武装**：自动搜刮武器，22 句东方梗对话
- **19 成就**：从"第一鞭"到"刑部尚书"
- **引雷特效**：蓝色光柱→闪电炸裂→冲击波→电流缠绕

## 起义怎么解决

| 方法 | 操作 | 说明 |
|------|------|------|
| 武力镇压 | 击杀所有起义工人 | 该区域工人暂时罢工 |
| 等待平息 | 等起义时间结束 | 起义自动结束 |
| 支付赎金 | 手持**绿宝石**右键起义首领 | 付够即可和平结束 |
| 敲钟平息 | 敲响任意钟 | 和平使者成就 |
| 引雷镇压 | 用引雷拴绳/钟镇压 | 雷电法王成就 |

## 配置

`config/createlaborrush-common.toml`

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| `destroyChance` | 0.15 | 加工时物品销毁概率 |
| `destroyRatioMin` | 0.2 | 销毁时最少损失比例 |
| `destroyRatioMax` | 0.5 | 销毁时最多损失比例 |
| `enableRebellion` | false | 启用起义系统 |
| `rebellionDuration` | 300 | 起义持续时间（秒） |
| `canDestroyDevices` | true | 起义工人能否拆家 |
| `destroyIntensity` | 0.5 | 拆家强度（0~1） |
