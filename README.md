# Create: Labor Rush

[![Modrinth](https://img.shields.io/badge/Modrinth-Create_Labor_Rush-00AF5C?logo=modrinth&logoColor=white)](https://modrinth.com/project/iD2FJnQa)

**简体中文** | [English](README.en.md) | [Русский](README.ru.md)

拴绳抽打加速工人，附魔解锁火焰批量/引雷特效，敲钟全员号召，压迫过头触发工人起义，还能给工人扣上批斗大会高帽、资本帽和亲手写字的挂牌，19 个成就等你解锁。

---

## 用法

| 操作 | 效果 |
|------|------|
| **拴绳**左键工人 | 90 秒"干活！"效果 |
| **钟**右键 | 16 格内全体工人加速 |
| **Shift+左键** | 闪电五连鞭（5 格 AOE） |

| 拴绳 | 等级 | 批量 |
|------|------|------|
| 普通 | Work I | 默认 |
| 火焰附加 I | Work II | 32 |
| 火焰附加 II | Work III | 64 |
| 引雷 | Work III | 64 |

## 新特性

- **附魔钟**：钟可附魔火焰附加/引雷，敲响触发特效，持久化存储
- **工人起义**（默认关闭）：传染、首领、力量 Buff、绿宝石谈判
- **女仆武装**：自动搜刮武器，22 句东方梗对话
- **19 成就**：从"第一鞭"到"刑部尚书"
- **引雷特效**：蓝色光柱 → 闪电炸裂 → 冲击波 → 电流缠绕
- **图形化配置**：游戏内"模组 → Config"直接调整，改完即时生效
- **多人联机**：配置以服务端为准，只有管理员能改并同步给所有人
- **批斗大会高帽 / 资本帽**：占头盔位的自定义模型帽子（3 防御 / 1 韧性），女仆也能戴
- **挂牌**（暂未启用）：原版悬挂告示牌可以挂进胸甲栏或挂到工人身上，写字界面自己写 4 行
- **标语画作**：4×3 的「时间就是金钱，效率就是生命」
- **三语本地化**：简体中文 / English / Русский

## 起义怎么解决

| 方法 | 操作 | 说明 |
|------|------|------|
| 武力镇压 | 击杀所有起义工人 | 该区域进入长罢工冷却 |
| 等待平息 | 等起义时间结束 | 起义自动结束，冷却较短 |
| 支付赎金 | 手持**绿宝石**右键起义首领 | 付够即可和平结束 |
| 敲钟平息 | 在起义区域内敲响钟 | 和平结束；和平使者成就 |
| 引雷镇压 | 引雷拴绳 **Shift+左键**（闪电五连鞭）命中起义者 | 雷电法王成就 |

> `enableRebellion` 只控制**是否触发新起义**。已经爆发的起义不受开关影响，上面五种方式都照常可用。

## 高帽 / 资本帽 / 挂牌

| 物品 | 合成 | 说明 |
|------|------|------|
| **批斗大会高帽** | Create 纸板 ×5 | 占头盔位，3 防御 / 1 韧性，女仆也能戴 |
| **资本帽** | 黑羊毛 ×4 + 红色染料 ×1 | 同上，黑呢礼帽 |
| **标语画作** | 原版画作流程 | 4×3，画面是「时间就是金钱／效率就是生命」 |

> 1.20.1 的画作需要一面**至少 4 格宽 × 3 格高**的墙，放画时才会随机抽到这张。

挂牌用的就是**原版悬挂告示牌**，不新增物品。文字存在牌子上，放下当方块时文字也带得过去。

> **本版本挂牌功能暂未启用**（写字渲染还有未解决的问题），下面这张表是设计目标，当前右键没有任何附加行为，悬挂告示牌就是完全的原版行为。

| 操作 | 效果 |
|------|------|
| 手持告示牌 + **右键空气** | 打开写字界面，写 4 行字 |
| 手持告示牌 + **潜行 + 右键空气** | 换到自己的胸甲栏（原胸甲回到手上） |
| 手持告示牌 + **右键工人** | 把牌子挂到工人胸前（消耗一块牌子） |
| **潜行 + 空手 + 右键工人** | 把牌子取回来 |

## 配置

游戏内 **模组列表 → Create: Labor Rush → Config** 直接用图形界面调整，改完即时生效（无需重启）；也可以直接改 `config/createlaborrush-common.toml`。

| 配置项 | 默认值 | 范围 | 说明 |
|-------|-------|------|------|
| `destroyChance` | 0.15 | 0.0–1.0 | 加工时物品销毁概率 |
| `destroyRatioMin` | 0.2 | 0.0–1.0 | 销毁时最少损失比例 |
| `destroyRatioMax` | 0.5 | 0.0–1.0 | 销毁时最多损失比例 |
| `enableRebellion` | false | 布尔 | 启用起义系统（只控制是否触发新起义） |
| `rebellionTriggerTime` | 300 | 10–3600 | 工人累计干活满该秒数后才可能起义 |
| `rebellionChance` | 0.05 | 0.0–1.0 | 每 10 秒一次检测的基础触发概率 |
| `rebellionDuration` | 300 | 5–600 | 起义持续时间（秒） |
| `rebellionRadius` | 5 | 1–32 | 起义检测半径（方块） |
| `canDestroyDevices` | true | 布尔 | 起义工人能否拆家 |
| `destroyCooldown` | 10 | 1–60 | 同一叛军两次拆家之间的冷却（秒） |
| `destroyIntensity` | 0.5 | 0.0–1.0 | 拆家强度 |

多人游戏下配置以**服务端**为准：只有管理员（OP，或单人/局域网房主）的修改会被接受并同步给所有人，其他玩家的修改会被拒绝并在聊天栏提示。客户端的本地配置文件不会被服务端下发的值写入。
