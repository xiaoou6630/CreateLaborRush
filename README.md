### 拴绳一甩、钟声一响，工人起飞 —— 附魔钟、工人起义与 19 个成就

这是 **Create: Villager Labor（机械动力：村民劳工）** 的附属模组：用拴绳抽打单个工人，或者敲钟号召附近全体工人，让他们以极快的速度干活。

**v2.0.1 新增：** 游戏内图形化配置（多人下只有管理员能改并同步）、自定义模型的批斗高帽与资本帽、4×3 标语画作、俄语本地化。

## 怎么用

- **拴绳（普通）** —— 左键坐着干活的工人，给他 90 秒「干活！」效果。
- **拴绳 + 火焰附加 I** —— 左键即可触发 **Work II**，每批 **32** 个。
- **拴绳 + 火焰附加 II** —— 左键即可触发 **Work III**，每批 **64** 个。
- **拴绳 + 引雷** —— 先左键工人，再 **Shift + 左键** 放出**闪电五连鞭**：5 格范围连锁打击，全新雷击特效（光柱 → 炸裂 → 冲击波 → 电流缠绕）。
- **实机演示：** [闪电五连鞭（bilibili）](https://www.bilibili.com/video/BV1Y24y1g759/?share_source=copy_web&vd_source=a4a9ee56bb8c9d1119a8298c1a1d3b2a&t=25)
- **钟 / 桌上铃** —— 右键敲响，让 **16 格内所有坐着的工人**一起加速；附魔过的钟同样有效。
- **附魔钟** —— 在铁砧上给钟附上**火焰附加**或**引雷**，摆下去，此后每次敲响都会触发附魔。附魔数据存在方块上，**重启世界也不会丢**；创造模式中键即可复制一块带附魔的钟。

> 小提示：拴绳也可以在铁砧上用附魔书附魔。

## 效果一览

处于「干活！」效果的工人会以最高速度冲过配方：

| 阶段 | 平时 | 有「干活！」 |
|------|------|--------------|
| 加工耗时 | 10-20 tick | 1 tick |
| 物品间隔 | 20 tick | 1 tick |

### 批量处理

| 触发方式 | 模式 | 每批数量 |
|----------|------|----------|
| 钟 / 普通拴绳 | Work I | 座位材质默认值（1/2/4） |
| 火焰附加 I 拴绳 | Work II | 32 |
| 火焰附加 II 拴绳 | Work III | 64 |

> 一轮总耗时从大约 1-2 秒降到 **2 tick（0.1 秒）**，适合大面积量产线。

## 工人起义（v2.0 新增）

压迫过头，工人是会翻脸的。这套系统是**可选**的，**默认关闭**——想找刺激就去配置里打开。

- **传染** —— 一个暴躁工人能把整间车间都带起来
- **起义首领** —— 每次起义都有首领（用 BOSS 条显示），起义期间叛军会获得力量加成
- **拆家** —— 叛军会砸附近的机器（可配置）
- **绿宝石谈判** —— 右键首领付够绿宝石，和平结束罢工
- **女仆武装** —— 装了车万女仆（Touhou Little Maid）时，女仆会自动抄起武器并喊出 22 句东方梗台词；没装则静默跳过

### 怎么平息起义

| 方式 | 操作 | 说明 |
|------|------|------|
| 武力镇压 | 击杀所有起义工人 | 之后工人会长期罢工 |
| 等待平息 | 等起义时间结束 | 自动结束 |
| 支付赎金 | 手持绿宝石右键首领 | 和平结束 |
| 敲钟平息 | 在起义区域内敲响任意（附魔）钟 | 解锁「和平使者」成就 |
| 引雷镇压 | 用引雷拴绳击打起义者 | 解锁「雷电法王」成就 |

> `enableRebellion` 只控制**是否触发新起义**，已经爆发的起义不受开关影响。

## 平衡性 —— 欲速则不达

干得太快是有代价的：在「干活！」状态下完成的物品，有**可配置的概率**会被销毁。

触发销毁时，**只损失这一批的一部分**（默认 20%-50%），而不是整批全没。

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| `destroyChance` | `0.15` | 销毁概率（0.0-1.0） |
| `destroyRatioMin` | `0.2` | 触发时最少损失比例（0.0-1.0） |
| `destroyRatioMax` | `0.5` | 触发时最多损失比例（0.0-1.0） |
| `enableRebellion` | `false` | 起义系统开关（只影响新起义） |
| `rebellionTriggerTime` | `300` | 工人累计干活满该秒数后才可能起义 |
| `rebellionDuration` | `300` | 起义持续时间（秒） |
| `canDestroyDevices` | `true` | 起义工人能否拆家 |
| `destroyCooldown` | `10` | 同一叛军两次拆家之间的冷却（秒） |
| `destroyIntensity` | `0.5` | 拆家强度（0.0-1.0） |

**举例：** Work III 处理 64 个物品，有 15% 概率触发销毁；一旦触发，随机损失 13-32 个，其余正常产出。

配置可以在游戏内 **模组列表 → Create: Labor Rush → Config** 直接调（改完即时生效），也可以直接编辑 `config/createlaborrush-common.toml`。

多人游戏下配置以**服务端为准**：只有管理员（OP，或单人/局域网房主）的修改会被接受并同步给所有人；服务端下发的值不会写进客户端的本地配置文件。

## 特性

- 支持**全部工位**：锯、压机、搅拌机、磨石、部署器
- **附魔钟**（火焰附加 / 引雷），数据持久保存
- **工人起义**系统：传染、首领、谈判，以及 5 种平息方式
- **19 个成就**：从「第一鞭」到「刑部尚书」
- **全新引雷特效**（光柱 → 炸裂 → 冲击波 → 电流缠绕）
- **自定义模型帽子**：批斗高帽、资本帽（占头盔位，3 防御 / 1 韧性，女仆也能戴）
- **标语画作**：4×3 的「时间就是金钱，效率就是生命」
- 兼容**车万女仆**（女仆既可以被鞭策，也会参与起义）
- 兼容 **Millénaire** 村民（反射实现，可选）
- **火焰附加**超频：每批 32 / 64 个
- **工人不再被火焰伤害**：烧不着
- 销毁概率与损失比例完全可配置
- 不动任何核心代码，纯 Mixin 附属

## 说明

- 「干活！」效果有自定义状态图标（红色）
- 火焰附加拴绳会在工人身上产生火焰/灵魂火粒子（纯视觉，不造成伤害）
- 敲钟可以一次性激励整间车间
- 效果持续 **90 秒（1800 tick）**
- 起义**默认关闭**——把 `enableRebellion` 打开即可体验
